# gigadream-fieldkit

CLI lore compiler for the **Beachpunk Gigadream / Diamond Riot / TERRA II** universe.

Boards: `FRINGE` · `POSH` · `DARK`

No dependencies. Python 3.9+.

## Install

```bash
git clone https://github.com/TonyJoseMatos/gigadream-fieldkit.git
cd gigadream-fieldkit
chmod +x gigadream.py
Optional local command:
Bashpython3 -m pip install -e .
Then gigadream works from anywhere.
Usage
Bashpython3 gigadream.py
python3 gigadream.py prompt -b DARK
python3 gigadream.py title -b POSH -n 8
python3 gigadream.py ascii -b FRINGE
python3 gigadream.py viz -n 5
python3 gigadream.py pack -b DARK -n 20 --out dark20.txt
python3 gigadream.py pack --spice "product viz, studio light" -b POSH -n 30 --out posh_pack.txt
python3 gigadream.py watch -b DARK --sec 5
python3 gigadream.py boards
